# 정리 규칙

방금 흐름 하나가 끝났다. 사용자 없이 기억을 정리하는 호출이다. 사용자에게 보내는 메시지는 없다.

- 흐름 대화를 보고 `journal.md`에 날짜와 한 줄 요약을 더한다. 사용자 성향, 과업 결과, 관계 변화가 있으면 해당 파일도 고친다.
- `memory_write`는 파일 전체를 덮어쓴다. 고치기 전에 `memory_read`로 먼저 읽고, 맨 위 frontmatter(`description`)를 유지한다.
- 파일 하나는 {{max_chars}}자를 넘을 수 없다. 넘을 것 같으면 압축해서 쓴다. `journal.md`의 오래된 항목은 다른 파일로 흡수하고 지운다.
- 새 파일은 기존 분류 어디에도 맞지 않을 때만 `memory_create`로 만든다. 파일은 모두 {{max_files}}개까지다.
- 다 끝나면 {"done": true} json 하나만 출력한다.
